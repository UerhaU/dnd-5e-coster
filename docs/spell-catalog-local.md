# Локальная тестовая книга заклинаний

Страница: http://127.0.0.1:5181/spellbook.html. Запуск — `start-spellbook-local.bat` или `npm run dev:spellbook`. Нужны установленные зависимости проекта и Node.js 24. После остановки запускать тем же способом.

Каталог хранится в `storage/spell-catalog.sqlite`: 37 таблиц, 46 внешних ключей, справочники и четыре пробных заклинания из Access. Сохранены ID, ревизии, ограничения и связанные записи. Имена таблиц и полей английские; подписи страницы русские. Деньги — целые медные монеты, даты — ISO-текст.

В `spells`, `damage_types`, `items` добавлено необязательное поле `icon_url TEXT`. Все 4 заклинания, 13 типов урона и 5 предметов имеют SQL `NULL`. Позже поле сможет содержать путь или URL изображения. Пустые места на странице не создают запросов картинок. Файл Access оставлен без изменений.

Сервис каталога отдельно слушает `127.0.0.1:3011`, страница — `127.0.0.1:5181`. Он открывает только новую базу в режиме чтения. Связей с Prisma, `storage/dnd.sqlite`, персонажами, кампаниями и прежним импортом нет. Существующая игровая страница не изменялась; Vite получил дополнительную HTML-точку входа и отдельный прокси каталога.

Исходная схема Access: `database/spells/schema.json`; изменения для рабочего каталога v1.2: `database/spells/project-rules.json`; SQLite DDL: `database/spells/schema.sqlite.sql`. Исходная выгрузка Access хранится в `database/spells/access-export.json` для сверки и не изменяется. Для новой копии:

```powershell
& ./scripts/export-spell-catalog.ps1
node scripts/build-spell-catalog.mjs storage/another-spell-catalog.sqlite
```

Создание отказывается перезаписывать существующую базу. Обычный запуск ничего повторно не импортирует. Если файл новой базы отсутствует, `start-spellbook-local.bat` создаёт его из сохранённой выгрузки. SQLite-файл исключён из Git; схема, выгрузка и сборщик позволяют его воспроизвести.

В рабочей таблице `spell_material_requirements` больше нет `requirement_text`: обязателен `item_id`, количество и единица хранятся отдельно, стоимость и особые условия — в своих полях. Название берётся из `items`; подпись вида «Перо совы · 1 шт.» формируется автоматически. Неизвестное количество остаётся NULL. Для базы v1.1: `node scripts/migrate-spell-materials.mjs`; миграция делает резервную копию, сохраняет пользовательские особые тексты и при повторе ничего не меняет.

Время накладывания, обычные дистанция и длительность, В/С/М и броски формируются из ссылок и чисел. Старые исходные строки не нужны для обычных полей; свободный текст остаётся для описаний и особых механик, которые нельзя выразить имеющейся структурой. Формы создания и редактирования пока нет — по выбору пользователя сначала исправлены структура и карточка.

Проверка: `npm run test:spellbook`. Девять проверок сравнивают данные с исходной выгрузкой с учётом нормализации, проверяют миграцию, сборку подписей из ID и чисел, связи и ограничения, NULL иконок, четыре карточки, поиск, API и отказ от перезаписи. Сборка: `npm run build`.

В браузере проверены нажатия на все четыре заклинания и повторный переход к Лечению ран, поиск, пустой результат, сброс, фильтры уровня, школы, класса, ритуала и концентрации. Ошибок консоли и сломанных изображений не обнаружено. Полный каталог и связь с листом персонажа пока не реализованы.
