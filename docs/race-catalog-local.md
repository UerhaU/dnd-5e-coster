# Пробный каталог рас 2014

Страница: http://127.0.0.1:5181/races.html. Запуск: `start-spellbook-local.bat` / `npm run dev:spellbook`, API `/api/spellbook/races`. Данные находятся в `D:/project/dnd web/storage/spell-catalog.sqlite`, вместе с 524 заклинаниями и 342 карточками снаряжения. К игровой базе и листу персонажа связи нет.

Добавлены только три расы для проверки: стандартный человек, дварф, эльф. Разновидности: холмовой и горный дварфы, высший и лесной эльфы. Альтернативный человек, дроу, прочие разновидности и расы пока не импортированы. Продолжение импорта — после пользовательской проверки образца.

Сверены текущие страницы [человека](https://5e14.dnd.su/race/81-human/), [дварфа](https://5e14.dnd.su/race/78-dwarf/), [эльфа](https://5e14.dnd.su/race/79-elf/). Рост/вес взяты из [таблицы Basic Rules 2014](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/personality-and-background), грузоподъёмность — из [правил Силы 2014](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/using-ability-scores). В HTML дварфа полные особенности повторяются в разновидностях; общие бонусы выделены отдельно и не дублируются. Старый импорт рас имел пустой `mechanicsJson`, поэтому его текст не выдавался за разобранные характеристики.

Структура добавляет 19 таблиц, в общей базе стало 103 пользовательские таблицы:

- `race_entries` — расы/разновидности, родитель, редакция, источники и ссылки на физические профили. Прибавки характеристик складываются, одноимённые скорости заменяются, владения/языки объединяются без дублей.
- `creature_sizes`, `creature_types` — общие размер с множителем грузоподъёмности и тип существа.
- `body_descriptions` — ориентиры роста/веса, возраст, продолжительность жизни и квалификаторы «свыше», «менее», «до». Это описание, не жёсткие пределы персонажа.
- `body_generators` — базовые рост/вес и ссылки на общие формулы кубиков. Рост хранится в дюймах, вес — в фунтах; показаны также см/кг. Один результат броска роста используется и для роста, и для прибавки веса. Формулы снаряжения и заклинаний переиспользуются по ID.
- `movement_modes`, `race_speeds`, `race_ability_bonuses` — виды перемещения, скорости и прибавки к общим ID характеристик.
- `languages`, `race_languages`, `proficiencies`, `race_proficiencies` — справочники и связи. Оружие ссылается на существующие предметы, броня — на категории. Названия оружия не копируются в текст расы.
- `race_traits`, `race_trait_links`, `race_trait_effects` — общие особенности и эффекты. Используются существующие эффекты, показатели, операции, условия и типы урона. Например, тёмное зрение 60 футов общее для дварфа и эльфа; один эффект преимущества спасброска используется с разными условиями против яда/очарования. Дварфийская выдержка — +1 к максимуму хитов за уровень; скорость лесного эльфа устанавливается в 35 футов.
- `race_choices`, `race_choice_options` — выбор языка, инструмента и заговора через внешние ключи. Заговор высшего эльфа ссылается на существующие заклинания волшебника нулевого уровня, характеристика — Интеллект. Уже известные языки исключены из дополнительных вариантов.
- `carrying_rules` — общее правило отдельно от веса тела: итоговая Сила × 15 фунтов × множитель размера; толкание/волочение/подъём — Сила × 30 × множитель. Маленький и Средний размеры имеют множитель 1, Крошечный — 0,5. Вес тела не вычитается из лимита снаряжения. Вариант «Нагрузка» пока не включён.
- `race_source_checks` — URL, дата и SHA-256 пяти исходных страниц.

На странице можно выбирать расу/разновидность, просматривать общие и добавленные особенности, варианты выбора, вводить результаты бросков и итоговую Силу/вес снаряжения. Выбор и расчёты служат проверке структуры и не сохраняют персонажа. Проверки обстоятельств расовых особенностей ещё не подключены к боевому автомату. Иконки оставлены SQL NULL.

Канонические данные: `scripts/race-samples-data.mjs`; миграция: `scripts/race-samples-model.mjs`; источники: `database/races/source-checks.json`; DDL: `database/races/schema.sqlite.sql`. Сборщик новой базы включает пробный набор автоматически. Для существующей базы: `npm run races:install`; повтор с тем же снимком безопасен, другой снимок требует отдельной миграции. Резервная копия перед установкой: `storage/backups/spell-catalog-before-race-samples-1792175796111.sqlite`. Рабочие файлы, загрузки и тестовые базы находятся на D.

`npm run test:races`: прошли 11 сценариев, включая наследование без дублей, общие ID, расчёты, владения, выбор заговора, API, ошибочную разновидность, ограничения, повторный импорт и откат ошибочной миграции. С прежними проверками прошёл 61 сценарий; frontend/backend собраны. В браузере проверены три расы, смена высшего/лесного эльфа (30/35 футов), выбор заговора, пример человека с бросками 12 и 3 (68 дюймов, 146 фунтов), превышение лимита груза.
