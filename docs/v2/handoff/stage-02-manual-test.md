# Ручная проверка выборки снаряжения и рас и английских названий компонентов (этап 2, Р71)

Дата: 2026-10-28. Проверял чат «Тестирование». Этап этим не принимается — принимает только автор.

## Как проверено

- **Программа:** полный каталог `apps/desktop/resources/catalog.db`, версия 9 (собран 2026-10-27, 286 предметов снаряжения + 265 компонентов заклинаний, 97 рас + 59 разновидностей). Данные карточек взяты прямо из базы (`content_revisions.data_json` и `rules_json`, связи `content_links`) — из них же строит карточку API. Окно программы глазами не осматривалось.
- **Сайт:** страницы DnD.su из ссылок выборки во встроенном браузере, 2026-10-28 (живой сайт, не кэш). На страницах рас текст брался из всех вкладок.
- **Поиск «щит»:** запросом к поисковому индексу базы — находятся и предмет, и заклинание. Само окно поиска закрыто тестом Playwright (коммит 736c8e5).
- **Английские названия компонентов:** все 265 записей `nameEn` из `data/reviewed/items/spell-components.json` сверены с текстом материальных компонентов этих заклинаний в английских книгах. Английский текст — по памяти (книг в проекте нет); спорные места помечены.
- Код не менялся.

## Ошибки рядом с выборкой (не из 30 строк)

Найдены при разборе строки «Дварф»: все навыки рас по каталогу просмотрены одним запросом.

1. **Навык «Расследование» не распознаётся.** В `packages/importer/src/races/parse-race-rules.ts` для Investigation стоит основа `/Анализ/` (старый перевод), а DnD.su пишет «Расследование». На сайте проверены:
   - кобольд MPMM — в программе выбор из 4 навыков, на сайте 5 (Магия, **Расследование**, Медицина, Ловкость рук, Выживание);
   - кендер — в программе 4, на сайте 5 (Проницательность, **Расследование**, Ловкость рук, Скрытность, Выживание);
   - ведалкен — в программе 5 навыков без Расследования, скорее всего та же причина (на сайте не открывал).
2. **Сатир MPMM: навыки.** В программе «1 на выбор из Выступление, Убеждение» / на сайте «владение навыками Выступление и Убеждение» — оба навыка постоянные. У сатира MOT всё верно.
3. **Кобольд MPMM:** «Хитрость» — только один из трёх вариантов «Наследия кобольдов» (Хитрость / Неповиновение / Драконье чародейство). В программе выбор навыка записан как обычный навык расы, без связи с выбором наследия. Это вопрос модели, не опечатка.
4. **Вид существа «Фея»** у кентавра и сатира MOT — в «Только текстом», поле `creatureType` пустое. У ааракокры MPMM «Гуманоид» разобран. Для конструктора нужно решить, разбирать ли «Вы — Фея».

- «Масло» (Hallow, Guards and Wards, Reincarnate) связано с `item:oil` — «Масло (фляга)». Для Hallow и Reincarnate («rare oils») это не фляга лампового масла. Решать автору.
