## Предлагаемые решения для раздела 2

- **Английские названия снаряжения задаются вручную** (`data/reviewed/items/names.json`): в таблицах DnD.su их нет, а ID строится по ним (Р11). Названия — по PHB/DMG, это не текст правил. Строка без названия в файле не попадает в каталог и отмечается ошибкой сборки.
- **Механика снаряжения — `item-rules/v1`** (`packages/shared/src/catalog/item-rules.ts`): оружие, доспех или щит; заполняется разбором таблиц (`review_status: parsed`, `automation: assisted`). Общий словарь механики уточнит движок правил на этапе 4 (как Р49).
- **Кэш статей «Инвентарь»** — `storage/dndsu-articles/` (`--items-cache`), по образцу Р50.
- **Карточка объекта — одна схема с вариантом по категории** (`entityResponseSchema`) и полем `links` со связями в обе стороны; клиент: `api.entity(id)` вместо `api.spell(id)`.
- **Дополнительное оружие из приключений и всё со статьи «Огнестрельное оружие и взрывчатка» — `optionalRule: true`** (как в v0.1); в списке — пометка «вариант правил», фильтр «Только обычные правила».

Часть В:

- **Рост, вес, возраст — поле `body` в `race-rules/v1`**: зрелость и жизнь в годах, рост в дюймах и вес в фунтах диапазоном `{min, max}`, формула случайных роста и веса (база + кости; вес = база + бросок роста × кости веса). Ориентиры описания, а не пределы для персонажа. Поле разновидности, если не `null`, заменяет расовое. — уточнение Р69.

- **Компонент заклинания — вид предмета `spell_component`**; соответствия листов состава — `data/reviewed/items/spell-components.json` (`nameEn` / `itemId` / `skip` с причиной); лист без записи и без предмета с тем же названием — ошибка сборки. Книги компонента — как у заклинаний; ссылки на DnD.su нет. Лист состава хранит `itemId`. — уточнение Р60.
