# Выборка заклинаний для проверки автором (этап 1, Issue #12)

Дата: 2026-10-27. Каталог: версия 2, 524 заклинания, кэш `5e14.dnd.su` от 2026-10-16.

30 заклинаний подобраны на сложные случаи: ритуал, концентрация, реакция, несколько источников, материалы с ценой и расходуемые, «ё» в названии, особый доступ классов (TCE), компонент А, нестандартные время, дистанция и длительность, таблицы в описании. Каждое заклинание сравнивается с его страницей на DnD.su (ссылка в таблице).

## Как проверять

1. Откройте программу с полным каталогом. В папке проекта выполните в терминале:

   ```bash
   npm run dev
   ```

   Откроется окно «Костёр». (В zip из GitHub — только тестовый каталог на 22 заклинания, для выборки он не подходит.)
2. Нажмите «Справочник» → «Заклинания».
3. Для каждой строки таблицы ниже: введите название в поиск, откройте карточку и откройте страницу DnD.su по ссылке из таблицы (или по ссылке «DnD.su» в карточке).
4. Сравните в карточке: уровень и школу, время накладывания, дистанцию, компоненты, длительность, концентрацию и ритуал, классы и подклассы, источники, описание и «На больших уровнях». Отдельно — то, что написано в столбце «Что проверить».
5. Замечания запишите в столбец «Итог» (например: «ок» или «нет подкласса домен света») или просто перечислите номера строк с замечаниями в чате этапа.

Ошибки сайта исправляются файлом в `data/reviewed/spells/` (как «Подарок болтуна»), ошибки разбора — в коде импортёра.
