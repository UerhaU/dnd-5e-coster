# Выборка снаряжения и рас для проверки автором (этап 2)

Дата: 2026-10-28. Каталог: версия 9 — 524 заклинания, 286 предметов снаряжения и 265 «компонентов заклинания», 97 рас и 59 разновидностей. Кэш: статьи снаряжения от 2026-10-27, страницы рас `5e14.dnd.su` от 2026-10-27.

15 предметов и 15 рас подобраны на сложные случаи: свойства оружия с дистанцией и боеприпасом, формула КД, наборы, транспорт, вариант правил, зелье, инструменты и связи с расами, компонент заклинания без страницы DnD.su; у рас — вкладки и общее у расы, разновидности, книги-повторы, увеличение на выбор, рост/вес/возраст числами, инструменты, особенности «только текстом». Каждый объект сравнивается со страницей DnD.su (ссылка в таблице). Проверку проводит чат «Тестирование».

## Как проверять

1. Откройте программу с полным каталогом. В папке проекта выполните в терминале:

   ```bash
   npm run dev
   ```

   Откроется окно «Костёр». (В zip из GitHub — только тестовый каталог, для выборки он не подходит.)
2. Нажмите «Справочник». Название из таблицы можно ввести в общую строку поиска — найдутся объекты всех категорий, у каждого подписана категория.
3. Откройте карточку и страницу DnD.su по ссылке из таблицы (у предметов — статья со всей таблицей снаряжения, найдите строку поиском по странице, Ctrl+F).
4. Сравните то, что написано в столбце «Что проверить». Значения в столбце — то, что показывает программа; на сайте должно быть то же.
5. Замечания запишите в столбец «Итог» («ок» или что не так) или перечислите номера строк с замечаниями в чате.

Ошибки сайта и английские названия исправляются файлами в `data/reviewed/items/` и `data/reviewed/races/`, ошибки разбора — в коде импортёра.
