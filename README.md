# Костёр

Портативная программа для Windows для игры в D&D 5e (редакция 2014) на русском языке. Правила и данные — по [DnD.su](https://dnd.su), подача интерфейса — по мотивам Baldur's Gate 3.

Одна программа работает в двух режимах: мастер открывает игру, игроки подключаются к нему в домашней сети или через интернет. Своих персонажей можно создавать и хранить без подключения.

**Версия 2.0.0-alpha.0 — каркас.** Сейчас программа открывает окно и проверяет, что встроенный сервер и база SQLite работают. Каталог, персонажи и игра появятся на следующих этапах (план — в [технической документации](docs/v2/technical-documentation.md), раздел 11).

## Как запустить

1. Скачайте `Koster-<версия>-win-x64.zip`.
2. Распакуйте его туда, где разрешена запись: например, в «Документы» или на флешку. Не в `Program Files`.
3. Запустите `Koster\Koster.exe`. Устанавливать ничего не нужно, Node.js не нужен.

Все данные программа хранит в папке `data` рядом с `Koster.exe` и больше никуда не пишет. Чтобы обновить программу, замените всё, кроме `data`.

Программа пока не подписана, поэтому Windows SmartScreen или антивирус могут предупредить о неизвестном издателе. В окне SmartScreen нажмите «Подробнее» → «Выполнить в любом случае».

Нужна Windows 10 или 11, 64-разрядная.

## Разработка

Нужны Windows 10/11 x64 и Node.js 24 LTS.

```
npm ci              # зависимости и Electron
npm run dev         # окно программы с горячей перезагрузкой интерфейса
npm run check       # lint + typecheck + тесты
npm run dist        # собрать zip: apps/desktop/release/Koster-<версия>-win-x64.zip
```

В режиме разработки данные программы лежат в `storage/dev-data/`. Папка `storage/` не попадает в git.

Устройство проекта (раздел 4.3 документации):

```
apps/desktop/        Electron: главный процесс, preload, окно, сборка zip
packages/ui/         интерфейс (React)
packages/server/     встроенный сервер (Fastify), слушает только 127.0.0.1
packages/shared/     общие типы и схемы Zod
packages/db/         базы catalog.db и user.db (этап 1)
packages/rules/      движок правил (этап 4)
packages/importer/   импорт DnD.su (этап 1, только для разработки)
data/reviewed/       проверенные вручную правила и исправления
data/fixtures/       сохранённые страницы для тестов
docs/                ТЗ, правила создания персонажа, документация v2
design/              ссылки на Figma и решения по дизайну
```

Документация: [техническая документация v2](docs/v2/technical-documentation.md), [ТЗ](docs/dnd5e_2014_interactive_app_spec.md), [правила создания персонажа](docs/character-creation-rules-engine.md).
